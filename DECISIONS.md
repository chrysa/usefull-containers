# DECISIONS — usefull-containers

> Architecture Decision Records reconstructed from repo evidence. Where the
> original rationale is not recorded, context/consequences are tagged UNKNOWN.

## D-0001 — Disposable containers over host-installed toolchain (FACT)

- **Decision:** Package each Python quality tool as a Docker image run one-shot
  against `${PWD}:/app`.
- **Rationale (INFERENCE):** avoid per-host/per-project toolchain installs;
  reproducible CI.
- **Evidence:** `README.md`, per-tool dirs.

## D-0002 — Compose `extends` aggregation (FACT)

- **Decision:** Root `docker-compose.yaml` composes per-service files via
  `extends`; root `Makefile` includes every `*.Makefile`.
- **Consequence:** each tool is self-contained; fleet operated from root.

## D-0003 — GitVersion (GitHubFlow) semver + Docker Hub publish (FACT)

- **Decision:** CI derives versions with GitVersion, publishes tooling images to
  `chrys4`. App images stay local (`DOCKER_REPO=local`).
- **Evidence:** `GitVersion.yml`, `build-and-publish.yml`, `README.md`.

## D-0004 — Vendored chrysa shared standards (FACT)

- **Decision:** `standards/`, `.claude/` hooks/skills, and managed CLAUDE.md
  blocks are synced from `chrysa/shared-standards` via `distribute-standards.sh`.
- **Consequence:** do not hand-edit; changes flow from the canon repo.

## D-0012 (referenced) — Generated context files (FACT)

  `scripts/gen_context_files.py`; regenerate with `make gen-context-files`.
